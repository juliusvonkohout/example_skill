# Dice Game Design Checklist

Use this checklist when writing or reviewing a dice game's rules.

- Name every player and state the starting score.
- State the number of dice and the legal number of sides on each die.
- Define turn order and every action available during a turn.
- Explain how a roll changes the score and when the turn ends.
- State the target and whether winning requires an exact score or a minimum.
- Define overshoot, ties, and any score reset or penalty.
- Confirm that the target is reachable under the stated rules.
- Check the lowest and highest legal roll near the target.
- Include a worked example clearly labeled as hypothetical.
- Keep actual dice results separate from examples and proposed rules.
